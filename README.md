# Started-AI — propuesta interactiva

Experiencia web de presentación comercial para Started-AI.

## Contenido

- Portada cinematográfica con transición futurista.
- Cinco pantallas navegables sobre costes, fabricación, servicio y propuesta.
- Navegación por clic, teclado y gesto táctil.
- Diseño adaptable a ordenador y móvil.

## Publicación

La experiencia se publica con GitHub Pages desde la carpeta `docs` de la rama `main`.
